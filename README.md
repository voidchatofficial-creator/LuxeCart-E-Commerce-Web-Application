# LuxeCart | Modern Luxury E-Commerce Platform

A premium, production-based e-commerce platform designed to deliver a seamless and luxurious shopping experience. This project demonstrates a full-stack web application complete with a secure admin panel, user authentication, a dynamic product catalog with advanced filtering and sorting, a robust cart and checkout flow, and payment gateway integration.

## Key Features
- **Integrated Admin Panel:** A secure, back-end connected admin dashboard for managing products, categories, sales, and order data.
- **Dynamic Product Filtering & Sorting:** Advanced catalog navigation allowing users to filter by category (Women, Men, Accessories, Fragrance, Home), search by name, and sort by Featured, Price (low to high / high to low), and Top Rated.
- **Quick-Add & Cart Management:** Frictionless "Quick add" functionality across collections, real-time cart item tracking, and complimentary shipping calculation on orders over $150.
- **Secure Authentication:** Real user sign-up and sign-in powered by Firebase Authentication, including "Continue with Google" support.
- **Intuitive Checkout & Payment Integration:** Structured checkout flow capturing shipping and contact details with secure PayPal integration (extensible to Razorpay, Stripe, Apple Pay, and Google Pay via API).

## Tech Stack
- **Frontend:** React, TypeScript
- **Backend & Authentication:** Firebase
- **Payments:** PayPal
- **Deployment:** Vercel
